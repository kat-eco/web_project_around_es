# Tripleten web_project_around_es

Esta página web funciona como una especie de blog de viaje. Se implementan herramientas de Java Script que dan una mayor interactividad: Se pueden agregar y eliminar tarjetas personalizadas, cambiar el nombre y descripción del autor, dar like a las tarjetas, y abrirlas para verlas más grandes.
