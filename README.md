# Tripleten web_project_around_es

Esta página web funciona como una especie de blog de viaje. Se implementan herramientas de Java Script que dan una mayor interactividad: Se pueden agregar y eliminar tarjetas personalizadas, cambiar el nombre y descripción del autor, dar like a las tarjetas, y abrirlas para verlas más grandes.

SPRINT 7:
En esta ocasión se han agragado métodos de validación de formularios que personalizan la página y ayudan a la interacción de los usuarios. Se han combinado tecnologías de JavaScript, HTML, y CSS para lograr este resultado.

De momento se utilizan los mensajes por Default que da el navegador, pero se puede mejorar dando los mensajes que el administrador decida.
